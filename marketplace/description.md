Polyglot Slides duplicates the parts of a deck you choose and translates the
copies into the languages you pick — so one presentation can serve a classroom
that reads in Spanish, Chinese, Vietnamese, Arabic and more.

**Three ways to translate**

- **Duplicate selection per language** — select some text boxes, a table, or
  a group, and get one translated copy of that cluster per language, stacked
  below the originals with the layout preserved. Highlight text inside a box
  instead and the translations are appended as new paragraphs.
- **Duplicate current slide per language** — one translated copy of the slide
  per language, inserted right after it.
- **Duplicate all slides per language** — the same for the whole deck, in
  order: slide 1, slide 1 (ES), slide 1 (ZH), slide 2, …

**Built for teachers**

- Pick languages once in the sidebar; the choice is remembered per user.
- Nothing is changed until every translation has succeeded, so a network hiccup
  never leaves a half-translated deck.
- Uses Google Translate through Google's own Apps Script service. No account to
  create, no API key, no cost.

**Privacy**

The add-on only touches the presentation it is open in, and only when you run
it. It stores nothing except your language preferences (in your own Google
account), sends text only to Google Translate, and has no server of its own.
